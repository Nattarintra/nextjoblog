# NextJobLog

Job application tracker built with Next.js (App Router) and Supabase.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router, Server Components/Actions)
- Supabase (Postgres, Auth, Storage) — schema and RLS policies in `supabase/migrations/`
- Tailwind CSS
